# Contributing to this fork

Use the [Mallet-Dev/open-seo repository](https://github.com/Mallet-Dev/open-seo) for changes to this workbench. Include the affected feature, setup, steps, expected outcome and actual result. Remove credentials and customer information from examples, screenshots and logs.

See the [local development guide](./LOCAL_DEVELOPMENT.md) and [quality guide](./QUALITY-EVALUATION.md) for installation and relevant checks. The [original OpenSEO project](https://github.com/every-app/open-seo) maintains its own contribution policy.
